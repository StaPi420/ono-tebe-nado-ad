# 1. Основы CSS

CSS (Cascading Style Sheets) — язык описания внешнего вида HTML-страницы.

HTML определяет структуру страницы, а CSS — её оформление.

Например, в HTML:

```
<h1 class="title">Привет, мир!</h1>
```

А в CSS:

```
.title {
    color: red;
    font-size: 40px;
}
```

В результате заголовок будет красным и размером 40 пикселей.

Разберём синтаксис:

```
.title {
    color: red;
    font-size: 40px;
}
```

- `.title` — селектор. Указывает, к какому элементу применяются стили.
- `{ }` — фигурные скобки, внутри которых находятся правила.
- `color` — CSS-свойство.
- `red` — значение свойства.
- `;` — завершает отдельное правило.

Точка перед названием означает, что мы обращаемся к HTML-элементу по его классу.

Например, `.cover` применяет стили ко всем элементам с `class="cover"`.

Важное различие: `margin` отвечает за внешние отступы элемента, а `padding` — за внутренние.

[Box Model Demystified: Margin, Border, Padding & Content - Euron Daily | Euron Community](https://images.openai.com/static-rsc-4/aNhJ5Hv9YEE0LLuFCrQxMEDQ_IPKsc85eHhW6jgkh1zwJmushl24aMsEIfzZ-IBueplaLN4JEmixTRp5c4x0W5xoEd_awQCsUM_soM1dg3XTeGKNvuWjldtPtK3xRPEZG3XYVu6RLJtWWmE16OvBHxsAIugXrPIUK_szeuHn_9k?purpose=inline)

Представь обычную коробку:

- `content` — содержимое коробки;
- `padding` — свободное пространство внутри коробки;
- `border` — граница коробки;
- `margin` — расстояние от коробки до других элементов.

Также тебе встретятся три основных единицы измерения:

| Единица | Значение                                              |
| ------- | ----------------------------------------------------- |
| `px`    | Пиксели — фиксированная величина                      |
| `%`     | Проценты относительно размеров родительского элемента |
| `em`    | Относительно размера шрифта текущего элемента         |
| `rem`   | Относительно размера шрифта корневого элемента        |

Например, если размер шрифта равен 20px, то `1.5em` будет равен 30px.

# 2. Шапка сайта — page-header

Начнём с первого блока:

```
.page-header {
    align-items: center;
    display: grid;
    grid-template-columns: 1fr min-content 1fr;
    padding: 92px 50px 96px;
}
```

`display: grid;`

Включает CSS Grid — систему размещения элементов в виде сетки.

В твоём HTML внутри `header` находятся три основных элемента:

1. Навигационное меню.
2. Логотип.
3. Контактная информация.

Grid позволяет расположить их в три колонки.

`grid-template-columns: 1fr min-content 1fr;`

Задаёт размеры трёх колонок.

- `1fr` — первая колонка занимает одну долю свободного пространства.
- `min-content` — вторая колонка занимает минимальную ширину, необходимую для содержимого.
- `1fr` — третья колонка занимает оставшееся свободное пространство.

Почему именно так?

Чтобы логотип находился строго по центру страницы, а меню и контакты располагались по краям.

`align-items: center;`

Выравнивает содержимое ячеек по вертикали относительно центра.

То есть логотип, меню и контакты располагаются на одной горизонтальной линии.

`padding: 92px 50px 96px;`

Задаёт внутренние отступы.

Когда у `padding` три значения, они означают:

```
padding: верхний левый-правый нижний;
```

В данном случае:

- `92px` — отступ сверху;
- `50px` — отступы слева и справа;
- `96px` — отступ снизу.

Зачем? Чтобы шапка не прилегала вплотную к краям страницы и между ней и главным экраном было достаточно пространства.

## Навигационное меню

```
.nav-menu__list {
    align-items: center;
    display: flex;
    flex-direction: row;
    font-size: 18px;
    gap: 26px;
    justify-content: start;
    margin: 0;
    padding: 0;
}
```

Здесь используется Flexbox — ещё один способ размещения элементов.

Если Grid удобен для создания сетки из строк и столбцов, то Flexbox особенно удобен для расположения элементов в одну линию.

`display: flex;`

Включает Flexbox. Дочерние элементы становятся flex-элементами и располагаются в одну строку по умолчанию.

`flex-direction: row;`

Указывает направление расположения элементов.

- `row` — в строку, слева направо.
- `column` — в столбец, сверху вниз.

В твоём случае пункты меню должны находиться рядом друг с другом.

`align-items: center;`

Выравнивает пункты меню по вертикали.

`font-size: 18px;`

Задаёт размер текста в 18 пикселей. Это достаточно крупный размер для навигации, чтобы ссылки хорошо читались.

`gap: 26px;`

Создаёт расстояние между соседними элементами Flexbox или Grid.

Почему 26px? Чтобы пункты меню не сливались друг с другом.

`justify-content: start;`

Выравнивает элементы в начале главной оси. Поскольку направление — `row`, элементы прижимаются к левому краю.

`margin: 0; padding: 0;`

Убирают стандартные отступы браузера у списка.

По умолчанию у HTML-списков есть собственные отступы и смещение. Мы убираем их, чтобы самостоятельно управлять расположением меню.

Следующие два правила:

```
.nav-menu__item--plain {
    list-style: none;
}

.nav-menu__item {
    list-style: circle;
    text-underline-offset: 0.25em;
}
```

`list-style: none;`

Убирает маркер списка.

`list-style: circle;`

Делает маркер в виде незакрашенного кружка.

Почему разные значения? В твоём меню первый пункт «Главная» не имеет кружка, а следующие пункты имеют.

`text-underline-offset: 0.25em;`

Регулирует расстояние между текстом и его подчёркиванием.

`0.25em` означает четверть текущего размера шрифта.

## Логотип и контакты

```
.brand-logo {
    align-items: center;
    height: 105px;
    justify-content: center;
    width: 148px;
}
```

- `height: 105px` — высота области логотипа.
- `width: 148px` — ширина области логотипа.
- `align-items: center` — вертикальное выравнивание дочерних элементов.
- `justify-content: center` — горизонтальное выравнивание дочерних элементов.

Последние два свойства работают только тогда, когда элемент является flex-контейнером или grid-контейнером. У тебя здесь не задан `display: flex` или `display: grid`, поэтому они фактически не работают. Это стоит исправить:

```
.brand-logo {
    display: flex;
    align-items: center;
    justify-content: center;
    height: 105px;
    width: 148px;
}
```

Далее:

```
.header-contact {
    justify-self: end;
}
```

`justify-self: end;`

Выравнивает сам элемент внутри его Grid-ячейки по горизонтали к правому краю.

Почему? Чтобы контактная информация располагалась справа в шапке.

```
.contact-block {
    font-size: 18px;
    font-style: normal;
    line-height: 1.5;
    max-width: 240px;
}
```

- `font-size: 18px` — размер текста.
- `font-style: normal` — обычное начертание шрифта. У тега `<address>` по умолчанию часто используется курсив, поэтому мы его убираем.
- `line-height: 1.5` — высота строки в полтора раза больше размера шрифта. При 18px это 27px.
- `max-width: 240px` — максимальная ширина блока. Текст не будет растягиваться бесконечно и при необходимости перенесётся на следующую строку.

```
.contact-block__list {
    line-height: 1.5;
    list-style: none;
    text-underline-offset: 0.25em;
}
```

- `line-height` — расстояние между строками.
- `list-style: none` — убирает маркеры списка.
- `text-underline-offset` — отодвигает подчёркивание ссылок от текста.

```
.contact-block__list--header {
    justify-self: end;
}
```

Прижимает список контактов к правому краю его Grid-ячейки.

# 3. Главный экран — cover

Это самый большой визуальный блок сайта. Здесь находятся фоновое изображение, заголовок «Оно тебе надо», рекламный слоган и кнопка.

```
.cover {
    background-image: url("../images/cover.jpg");
    background-position: 50% 50%;
    background-size: cover;
    padding: 165px 50px 50px;
    position: relative;
    z-index: -2;
}
```

`background-image: url("../images/cover.jpg");`

Устанавливает фоновое изображение.

- `background-image` — свойство для задания фонового изображения.
- `url()` — функция, которая указывает путь к файлу.

Почему `../images/cover.jpg`? Потому что CSS-файл находится в папке `styles`, а изображение — в соседней папке `images`. Две точки означают переход на уровень выше.

`background-position: 50% 50%;`

Определяет положение фонового изображения.

Первое значение — горизонтальное положение, второе — вертикальное.

- `0% 0%` — левый верхний угол.
- `50% 50%` — центр.
- `100% 100%` — правый нижний угол.

Почему центр? Чтобы при изменении размеров блока изображение обрезалось равномерно с разных сторон.

`background-size: cover;`

Определяет размер фонового изображения.

`cover` означает, что изображение масштабируется так, чтобы полностью заполнить весь блок.

При этом пропорции изображения сохраняются, но некоторые его части могут обрезаться.

Есть также `contain`: оно показывает изображение целиком, но при этом могут появиться пустые области.

`padding: 165px 50px 50px;`

Внутренние отступы:

- сверху — 165px;
- слева и справа — 50px;
- снизу — 50px.

Большой верхний отступ нужен, чтобы заголовок не находился непосредственно у верхнего края изображения.

`position: relative;`

Устанавливает относительное позиционирование элемента.

Сам по себе элемент остаётся в обычном потоке документа, но теперь его можно использовать как точку отсчёта для абсолютно позиционированных дочерних элементов.

В твоём случае это нужно для затемняющего слоя `.cover__shade`.

`z-index: -2;`

Управляет порядком расположения элементов по глубине.

Можно представить, что элементы находятся на разных слоях:

- `z-index: 2` — передний план;
- `z-index: 1` — средний план;
- `z-index: 0` — обычный слой;
- `z-index: -1` — слой позади;
- `z-index: -2` — ещё дальше.

У тебя используется отрицательное значение, чтобы поместить фоновый блок ниже затемняющего слоя.

Однако здесь есть потенциальная проблема: отрицательный `z-index` может отправить весь блок за фон родительского элемента. Если изображение или содержимое пропадает, стоит пересмотреть эти значения.

## Затемняющий слой

```
.cover__shade,
.lot-tile__shade {
    background-color: black;
    bottom: 0;
    left: 0;
    opacity: 60%;
    position: absolute;
    right: 0;
    top: 0;
    z-index: -1;
}
```

Обрати внимание: здесь два селектора через запятую.

Это означает, что одни и те же свойства применяются сразу к двум классам:

- `.cover__shade`;
- `.lot-tile__shade`.

`background-color: black;`

Устанавливает чёрный цвет фона.

`position: absolute;`

Включает абсолютное позиционирование.

Элемент перестаёт занимать место в обычном потоке документа и размещается относительно ближайшего позиционированного предка.

В данном случае таким предком является `.cover` или `.lot-tile`, у которых задано `position: relative`.

`top: 0; bottom: 0; left: 0; right: 0;`

Эти четыре свойства определяют положение элемента относительно всех четырёх сторон родителя.

Поскольку все значения равны нулю, элемент растягивается на всю площадь родительского блока.

`opacity: 60%;`

Устанавливает прозрачность элемента.

- `opacity: 1` — полностью непрозрачный.
- `opacity: 0.5` — наполовину прозрачный.
- `opacity: 0` — полностью прозрачный.

Здесь 60% означает, что чёрный слой достаточно плотный, но изображение под ним всё ещё видно.

Важная особенность: `opacity` влияет не только на фон, но и на всё содержимое элемента. Поэтому затемняющий слой вынесен в отдельный пустой `div`.

`z-index: -1;`

Располагает затемняющий слой позади содержимого карточки или обложки, но перед фоновым изображением.

## Заголовок

```
.cover__heading {
    display: flex;
    flex-direction: column;
    justify-content: center;
    line-height: 1.286;
}
```

`display: flex;`

Включает Flexbox.

`flex-direction: column;`

Располагает дочерние элементы вертикально, один под другим.

`justify-content: center;`

Выравнивает дочерние элементы по центру главной оси. Поскольку направление — `column`, это вертикальное центрирование.

`line-height: 1.286;`

Задаёт высоту строки относительно размера шрифта.

Например, при размере шрифта 100px высота строки составит примерно 128.6px.

Это нужно, чтобы строки заголовка располагались с определённым интервалом.

Далее:

```
.cover__line {
    color: white;
    font-size: 100px;
    font-weight: 700;
    letter-spacing: 0.3em;
    text-transform: uppercase;
}
```

- `color: white` — белый цвет текста.
- `font-size: 100px` — размер шрифта.
- `font-weight: 700` — жирность шрифта. Обычно 400 — обычный, 700 — жирный.
- `letter-spacing: 0.3em` — расстояние между буквами. При размере шрифта 100px это 30px.
- `text-transform: uppercase` — автоматически переводит текст в верхний регистр.

Почему такие значения? Заголовок должен быть крупным, жирным, белым и визуально занимать значительную часть обложки.

Теперь разберём три варианта расположения слов.

```
.cover__line--left {
    display: flex;
    justify-content: flex-start;
}
```

Первое слово «ОНО» располагается слева.

`justify-content: flex-start` прижимает содержимое к началу главной оси.

```
.cover__line--middle {
    display: flex;
    justify-content: center;
    margin-right: -0.3em;
}
```

Второе слово «ТЕБЕ» располагается по центру.

`margin-right: -0.3em;`

Отрицательный внешний отступ.

Обычно положительный `margin` увеличивает расстояние, а отрицательный позволяет сдвинуть элемент или изменить занимаемое им пространство.

Здесь он компенсирует дополнительный интервал, появившийся из-за `letter-spacing`.

```
.cover__line--right {
    display: flex;
    justify-content: end;
    margin-right: -0.3em;
}
```

Третье слово «НАДО» располагается справа.

`justify-content: end` прижимает содержимое к концу главной оси.

## Нижняя часть обложки

```
.cover__bottom {
    display: flex;
    flex-direction: row;
    justify-content: space-between;
    margin-top: 106px;
}
```

Здесь располагаются слоган и кнопка.

`display: flex;`

Включает Flexbox.

`flex-direction: row;`

Располагает элементы горизонтально.

`justify-content: space-between;`

Распределяет свободное пространство между элементами.

Первый элемент прижимается к левому краю, второй — к правому.

[CSS Flexbox Tutorial for Complete Beginners](https://images.openai.com/static-rsc-4/ntFfxhWSnkigd17YB-9oewtGwj9Na6-SynH5-RSSB5CzOllj2saQaEdvFBXjyPi-5PnPSF6dq-SCx9M8EL76zcBWCEESry9_L2jeiY0f-0pX_isWrjv9kCTDQJC9gxSEAJwx8THmOCzjM42jwpM_qGnHtJ8AnuhLWsNbasJjKmI?purpose=inline)

`margin-top: 106px;`

Создаёт внешний отступ сверху. Благодаря ему слоган и кнопка находятся достаточно далеко от заголовка.

Далее:

```
.cover__slogan {
    align-items: center;
    color: white;
    display: flex;
    font-size: 22px;
    text-transform: uppercase;
    word-spacing: 0.8em;
}
```

- `align-items: center` — выравнивает содержимое по вертикальному центру.
- `color: white` — белый цвет.
- `display: flex` — включает Flexbox.
- `font-size: 22px` — размер шрифта.
- `text-transform: uppercase` — заглавные буквы.
- `word-spacing: 0.8em` — увеличивает расстояние между словами на 0.8 размера текущего шрифта.

Почему увеличиваем `word-spacing`? Чтобы слоган выглядел более разреженным и визуально соответствовал дизайну обложки.

Кнопка:

```
.bid-btn {
    background-color: transparent;
    border-color: white;
    border-width: 1px;
    color: white;
    font-size: 22px;
    padding: 12px 32px 11px 31px;
    text-transform: uppercase;
}
```

- `background-color: transparent` — прозрачный фон. Видно изображение под кнопкой.
- `border-color: white` — белый цвет границы.
- `border-width: 1px` — толщина границы.
- `color: white` — белый цвет текста.
- `font-size: 22px` — размер текста.
- `padding: 12px 32px 11px 31px` — внутренние отступы: сверху 12px, справа 32px, снизу 11px, слева 31px.
- `text-transform: uppercase` — заглавные буквы.

Обрати внимание: `border-color` и `border-width` определяют цвет и толщину границы, но не её стиль. Для надёжного отображения лучше добавить:

```
border-style: solid;
```

Тогда граница точно будет сплошной линией.

```
    display: flex;
    flex-direction: column;
```

Здесь мы снова используем Flexbox.

- `display: flex` — включает Flexbox.
- `flex-direction: column` — располагает дочерние элементы вертикально.
- `margin-bottom: 120px` — отступ снизу.
- `margin-top: 180px` — отступ сверху.

Почему `column`? Потому что внутри блока сначала идёт заголовок, затем карточки, затем ссылка «посмотреть больше».

```
    margin-bottom: 27px;
    margin-left: 50px;
```

- `font-size: 40px` — размер заголовка.
- `margin-bottom: 27px` — расстояние между заголовком и карточками.
- `margin-left: 50px` — смещение заголовка от левого края.
- `text-transform: uppercase` — заглавные буквы.

## Сетка карточек

```
.lots__grid {
    display: flex;
    flex-direction: row;
    gap: 25px;
    justify-content: center;
    list-style: none;
```

- `display: flex` — включает Flexbox.
- `flex-direction: row` — располагает карточки горизонтально.
- `gap: 25px` — расстояние между карточками.
- `justify-content: center` — располагает всю группу карточек по центру.
- `list-style: none` — убирает маркеры списка.

Почему Flexbox? Потому что у нас три карточки, которые должны находиться в одной строке с одинаковым расстоянием между ними.

## Карточки лотов

Это общий класс для всех трёх карточек.

`color: white;`

Задаёт белый цвет текста. Он хорошо контрастирует с затемнёнными фоновыми изображениями.

`height: 596px;`

Задаёт высоту карточки.

Почему фиксированное значение? Чтобы все три карточки имели одинаковую высоту независимо от количества текста.

`width: 334px;`

Задаёт ширину карточки.

`padding: 48px 40px;`

Внутренние отступы:

- сверху и снизу — 48px;
- слева и справа — 40px.

Они нужны, чтобы текст не прилегал к границам изображения.

`position: relative;`

Создаёт систему координат для затемняющего слоя `.lot-tile__shade`.

Теперь он может растягиваться по всей площади карточки.

Разберём свойства:

- `background-image` — выбирает картинку для конкретной карточки.
- `background-position: 50% 50%` — располагает картинку по центру.
- `background-size: cover` — растягивает картинку так, чтобы она полностью покрыла карточку.
- `z-index: -2` — задаёт порядок расположения карточки по глубине.

Это хороший пример повторного использования CSS: общие свойства записаны один раз в `.lot-tile`, а индивидуальные — отдельно.

Небольшая проблема: сочетание отрицательного `z-index` у карточек и затемняющего слоя может привести к неправильному отображению. Об этом поговорим в разделе с исправлениями.

# 5. Блок «Об аукционе» — about

Это последний большой информационный раздел перед подвалом.

```
.about {
    margin-bottom: 180px;
    margin-left: 24px;
    margin-right: 24px;
}
```

- `margin-bottom: 180px` — отступ снизу, отделяет блок от подвала.
- `margin-left: 24px` — отступ слева.
- `margin-right: 24px` — отступ справа.

Почему не используем `padding`? Здесь мы хотим отделить весь блок от соседних элементов, а не создать внутреннее пространство внутри него.

## Общая структура

```
.about__wrap {
    display: grid;
    grid-gap: 72px;
    grid-template-columns: 240px 693px;
    justify-content: center;
}
```

Здесь снова используется Grid.

У нас два основных элемента:

1. Круглый логотип.
2. Текстовая часть.

`display: grid;`

Включает сеточную систему.

`grid-gap: 72px;`

Устанавливает расстояние между колонками и строками сетки.

В данном случае между логотипом и текстом будет 72px.

Это устаревшее название свойства. Современный аналог:

```
gap: 72px;
```

`grid-template-columns: 240px 693px;`

Создаёт две колонки:

- первая — 240px;
- вторая — 693px.

Почему фиксированные размеры? Чтобы логотип и текстовая часть занимали определённое место, соответствующее макету.

`justify-content: center;`

Располагает всю сетку по центру родительского блока.

## Круглый логотип

```
.about__badge {
    align-items: center;
    background-color: black;
    border-radius: 100rcap;
    display: flex;
    height: 240px;
    justify-content: center;
    justify-self: right;
    margin-top: 35px;
    width: 240px;
}
```

- `align-items: center` — выравнивает содержимое по вертикали.
- `background-color: black` — чёрный фон.
- `border-radius: 100rcap` — скругляет углы. В данном случае подразумевается создание круга.
- `display: flex` — включает Flexbox.
- `height: 240px` — высота круга.
- `justify-content: center` — выравнивает логотип по горизонтали.
- `justify-self: right` — выравнивает сам элемент по правому краю Grid-ячейки.
- `margin-top: 35px` — отступ сверху.
- `width: 240px` — ширина круга.

Что такое `border-radius`?

Это свойство отвечает за скругление углов.

Например:

```
border-radius: 0;
```

Углы прямые.

```
border-radius: 10px;
```

Углы немного скруглены.

```
border-radius: 50%;
```

При одинаковой ширине и высоте получается круг.

В твоём случае я бы заменил `100rcap` на более привычное и понятное:

```
border-radius: 50%;
```

Так ты точно получишь круг.

Далее:

```
.about__badge-img {
    height: auto;
    width: 148px;
}
```

- `width: 148px` — ширина изображения логотипа.
- `height: auto` — автоматический расчёт высоты с сохранением исходных пропорций.

Почему `auto`? Чтобы логотип не растягивался и не деформировался.

## Текстовая часть

```
.about__content {
    justify-self: left;
    margin-top: 133px;
}
```

- `justify-self: left` — прижимает элемент к левому краю Grid-ячейки.
- `margin-top: 133px` — смещает текстовую часть вниз относительно верхнего края родительского блока.

```
.about__heading {
    font-size: 40px;
    text-transform: uppercase;
}
```

- `font-size: 40px` — крупный размер заголовка.
- `text-transform: uppercase` — заглавные буквы.

Теперь текст:

```
.about__body {
    display: flex;
    flex-direction: column;
    font-size: 20px;
    gap: 24px;
    margin-top: 100px;
}
```

- `display: flex` — включает Flexbox.
- `flex-direction: column` — располагает абзацы вертикально.
- `font-size: 20px` — размер текста.
- `gap: 24px` — расстояние между абзацами.
- `margin-top: 100px` — расстояние между заголовком и текстом.

Почему `column`? Потому что два абзаца должны идти друг под другом.

Последнее правило:

```
.about__lead {
    width: 688px;
}
```

Устанавливает ширину первого абзаца в 688px.

Зачем? Чтобы контролировать длину строки и добиться нужного переноса текста, соответствующего макету.

# 7. Что в твоём CSS стоит исправить

Теперь самое полезное перед сдачей: посмотрим на несколько моментов, к которым преподаватель может придраться.

Я не предлагаю полностью переписывать проект. Лучше исправить несколько небольших недочётов, сохранив твою структуру.

1\. Логотип в шапке

Сейчас:

```
.brand-logo {
    align-items: center;
    height: 105px;
    justify-content: center;
    width: 148px;
}
```

Проблема: `align-items` и `justify-content` не работают без `display: flex` или `display: grid`.

Исправление:

```
.brand-logo {
    display: flex;
    align-items: center;
    justify-content: center;
    height: 105px;
    width: 148px;
}
```

2\. Скругление логотипа

Сейчас:

```
border-radius: 100rcap;
```

Лучше:

```
border-radius: 50%;
```

Это стандартный способ создания круглого элемента с одинаковой шириной и высотой.

3\. Затемнение изображений

Сейчас у тебя используются:

```
.cover {
    position: relative;
    z-index: -2;
}
```

И:

```
.lot-tile--cinema {
    z-index: -2;
}
```

При этом затемняющий слой имеет `z-index: -1`.

Такая комбинация может отправить содержимое за фон страницы. Я бы рекомендовал сделать следующим образом:

```
.cover,
.lot-tile {
    position: relative;
    isolation: isolate;
}

.cover__shade,
.lot-tile__shade {
    background-color: black;
    opacity: 0.6;
    position: absolute;
    inset: 0;
    z-index: -1;
}
```

А из `.cover`, `.lot-tile--cinema`, `.lot-tile--literature` и `.lot-tile--art` убрать отрицательные `z-index`.

Здесь появилось новое свойство:

`isolation: isolate;`

Оно создаёт для элемента отдельный контекст наложения. Благодаря этому отрицательный `z-index` затемняющего слоя не должен отправлять его за фон всей страницы.

Также `inset: 0` — сокращённая запись четырёх свойств:

```
top: 0;
right: 0;
bottom: 0;
left: 0;
```

4\. Размер карточек

У тебя:

```
.lot-tile {
    height: 596px;
    padding: 48px 40px;
    width: 334px;
}
```

Здесь есть важный нюанс.

По умолчанию CSS использует модель `content-box`. Это означает, что `width` не включает внутренние отступы.

Следовательно, фактическая ширина карточки составляет:

\\[ 334 + 40 + 40 = 414\text{px} \\]

А фактическая высота:

\\[ 596 + 48 + 48 = 692\text{px} \\]

Если в `global.css` уже установлен `box-sizing: border-box`, то расчёты будут другими. Поэтому обязательно проверь этот файл.

`box-sizing: border-box;` позволяет включить `padding` и границы в заданные ширину и высоту элемента.

Например:

```
* {
    box-sizing: border-box;
}
```

Это очень распространённый приём, который упрощает расчёт размеров элементов.

Не добавляй его вслепую перед сдачей: он изменит размеры уже существующих блоков, если сейчас используется `content-box`.

5\. Устаревшее свойство

В блоке `.about__wrap`:

```
grid-gap: 72px;
```

Можно использовать современную запись:

```
gap: 72px;
```

Они выполняют одинаковую задачу в твоём случае.

## Типичные вопросы преподавателя

Ниже несколько вопросов, которые я бы подготовил заранее.

1\. Чем отличается Flexbox от Grid?Flexbox предназначен преимущественно для расположения элементов в одном направлении (строка или столбец). Grid позволяет создавать двумерные сетки, управляя одновременно строками и колонками.

2\. Чем отличаются margin и padding?Margin — внешний отступ между элементом и соседними элементами. Padding — внутренний отступ между содержимым элемента и его границей.

3\. Что делает display: flex?Превращает элемент во flex-контейнер. Его непосредственные дочерние элементы становятся flex-элементами, которыми можно управлять с помощью flex-direction, justify-content, align-items и других свойств.

4\. В чём разница между justify-content и align-items?justify-content выравнивает элементы по главной оси, а align-items — по поперечной. Главная ось определяется flex-direction.

5\. Для чего нужен position: relative?Он позволяет позиционировать сам элемент относительно его обычного положения, а также создаёт систему координат для абсолютно позиционированных потомков.
